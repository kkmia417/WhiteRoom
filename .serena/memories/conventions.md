# Conventions

- No stable project-specific C# style existed at onboarding time; keep new code conventional Unity C# with serialized private fields and explicit namespaces where useful.
- Keep Unity assets under `Assets/` with matching `.meta` files generated by Unity when possible; manual asset creation should avoid brittle scene/prefab YAML unless necessary.
- Existing project uses UTF-8 files. Prefer ASCII for new code unless Japanese in dialogue/user-facing copy is intentional.
